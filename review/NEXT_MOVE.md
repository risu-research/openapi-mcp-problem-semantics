# Next move after v0.1.0-rc1: externalize the test

The core internal experimental argument is frozen. Do **not** add converter #4 or expand the corpus merely for volume.

## Highest-value next move

After the human-controlled publication gate is completed, expose RC1 to an external falsifier:

1. publish a repository/tag for `v0.1.0-rc1`;
2. attach or separately archive the exact raw evidence assets by SHA-256;
3. publish a stable technical timestamp before a preprint submission; and
4. invite one translator maintainer or independent practitioner to run the frozen profile against an implementation or fix.

The most valuable new result is not another internal failure. It is either:

- an independent reproduction;
- a maintainer fix that moves one tested target from LOSS to PRESERVED without changing the frozen corpus; or
- a principled critique that forces a new profile version rather than retroactive mutation of v0.1.0-rc1.

## Publication holds

Before public push, explicitly choose and record:

- repository/content/code license(s);
- author/contributor metadata;
- public repository owner/name; and
- whether raw historical evidence archives containing machine-local absolute paths are published as-is, sanitized as clearly labeled derivative artifacts, or retained privately with only hashes published.

These are release-governance choices, not scientific-result changes.
